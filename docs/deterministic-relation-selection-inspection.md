# Finite relation selection inspection

Inspected September 19, 2026. This update implements the approved member-selection control for finite constructions. Predicates and Quantifiers 83, 84, 87, 89, 95 and 96 now select the true predicate statements on the already specified domain `{a,b}`. Dedicated Review `quantifier-order-countermodel-variants` 1 and 2 select the relation's ordered pairs or visitor–guide pairs. Unselected members are absent; an explicit **None** submits the empty interpretation. The learner no longer has to mark every absent member false.

The selected members define the same complete finite interpretation as the former Boolean grids. The condition formulas, stable exercise/template IDs, original task hashes, official explanations, and production versus recognition evidence remain unchanged. Review reason labels now describe inputs and witnesses directly instead of referring to rows and columns in a removed table. The lesson decision and Review explanation remain required deterministic outputs.

Reinspected MIT's _Mathematics for Computer Science_ (2018), [§§3.6.3–3.6.6, printed pp. 65–68 / PDF pp. 73–76](https://courses.csail.mit.edu/6.042/spring18/mcs.pdf#page=73), for quantifier order, common domains, finite conjunction/disjunction interpretations, and validity under every predicate interpretation. Reinspected Hammack's _Book of Proof_, edition 3.4, [§2.7, printed pp. 53–55 / PDF pp. 65–67](https://richardhammack.github.io/BookOfProof/Main.pdf#page=65), for universal/existential truth conditions, and [§11.1, printed pp. 201–202 / PDF pp. 213–214](https://richardhammack.github.io/BookOfProof/Main.pdf#page=213), for relations as subsets of ordered pairs. The existing `m-quantifiers`, `p-quantifiers` and `review-domain-order` assignments support the unchanged mathematical content. These texts support the definitions, not the original app examples or a claim about UI effectiveness.

The authoring generators independently enumerate every interpretation: 16 subsets for each four-option input and four subsets for the one two-option input. Fixtures also check reversed selection order, a correct construction with an incorrect decision/reason, an explicit empty selection, and missing, null, or unknown selections. Both valid two-element separating relations remain accepted; arbitrary countermodels satisfying the lesson's conditions remain accepted. All 2,728 main-catalog fixtures and 141 dedicated Review fixtures pass the shared checker with the selection contract implemented.

Checked every remaining grid in all three lesson catalogs and every dedicated Review definition. No other grid constructs a relation by assigning truth to each candidate member. Relations 4 explicitly requests a Boolean matrix; Relations 11 and 22 request property classifications. Truth tables, truth-value evaluations, counterassignments with requested formula values, finite function output tables, matrix products, requested class members, and stamp counts retain their existing controls. Their requested outputs differ from choosing the members of a finite relation.
